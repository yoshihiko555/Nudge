# ADR-20261112-0015: メニューバーに件数を出し、取得に失敗したら件数の代わりに印を出す

- ステータス: 採用
- 決定日: 2026-11-12
- 関連: [ADR-0010](0010-background-polling.md) の「影響」（取得に失敗したらキャッシュを維持する）を、メニューバーの件数に限って一部置き換える。[ADR-0006](0006-global-hotkey.md)（ネイティブ API を使わない）と [ADR-0011](0011-homebrew-cask-distribution.md) の「影響」（署名・公証に未対応）を前提にする。件数の対象は [ADR-20261112-0013](ADR-20261112-0013-due-task-groups.md) と [ADR-20261112-0014](ADR-20261112-0014-habit-week-streak.md) で決めたもの

## 背景

- v1 では、メニューバーにアイコンだけを出していた（ラベルは空）。期限切れや残りの習慣は、小窓を開くまで分からなかった。
- 本人には「やり忘れに気づけない」という困りごとがあった（`docs/overview.md` の「v2」の「背景・目的」）。
- macOS のネイティブ通知は、Wails v3 alpha.53 の通知サービスを使えば出せる。ただし、パッケージ化と署名をしたアプリでなければ動かない（同サービスの `notifications_darwin.go` のコメントで確認）。Nudge は署名せずに配布している（ADR-0011）。
- Wails のトレイの `SetLabel` を使えば、Nudge 側に cgo やネイティブのコードを足さずに、アイコンの横に文字を出せる（ADR-0006 を守れる）。Wails v3 alpha.53 の `pkg/application/systemtray.go` の `SetLabel` は、メインスレッドで各 OS の実装を呼ぶだけで、呼び出し側に追加の連携は要らない（2026-11-12 にコードで確認）。
- v1 は、取得に失敗するとキャッシュを残して前の結果を出し続けていた（ADR-0010）。件数を主な合図にすると、失敗中に古い件数が出続けて、残りが無いように見えてしまう。

## 選択肢

### A. 通知で知らせる（不採用）

- 通知サービスは署名したアプリでしか動かず、Nudge は署名せずに配布している（ADR-0011）。

### B. メニューバーに件数を出し、失敗したらキャッシュの件数を出し続ける（不採用）

- 失敗に気づかないまま、古い件数を信じてしまう。

### C. メニューバーに件数を出し、失敗したら件数の代わりに印を出す（採用）

- 小窓を開かなくても残りが分かり、失敗中は「件数が当てにならない」ことも分かる。

## 決定

**メニューバーのアイコンの横に、期限切れと今日のタスクの数と、今日残っている習慣の数を出す。取得に失敗した DB があれば、件数の代わりに印を出す。**

1. **0 の項目**: 0 の項目は出さない。両方 0 なら、アイコンだけにする。
2. **複数の DB**: タスク・習慣の DB が複数あるときは、種類ごとに合算する。
3. **習慣の数**: 今日の対象で、今日がまだ未チェックで、今週の目標に届いていない習慣の数を出す（ADR-20261112-0014 の「決定」2・3）。
4. **失敗したとき**: 直近の取得に失敗した DB が 1 つでもあれば、件数の代わりに「!」を出す。小窓の一覧は、前の結果を出し続ける（ADR-0010 のまま）。習慣の過去の週の取得の失敗は、「!」に含めない。
5. **出さない間**: 起動して最初の取得が終わるまでは、件数を出さない。設定を保存した後の取り直しの間は、前の表示を残す。

## 検証

- 単体テストで、次の点を確かめた（`internal/app/tray_summary_test.go`）。
  - 表示の全パターン（空・「!」・片方だけ・両方）
  - 件数の集計
  - 取得の失敗の検出
  - 設定の保存の後に表示を残すこと
- 2026-11-12 に、本人が実機でアイコンの横に件数が出ることを確認した。

## 影響

- **良い影響**: 小窓を開かずに、期限切れと残りの習慣に気づける。
- **トレードオフ**: メニューバーの幅を数文字分使う。取得に失敗している間は件数が見えない。
- **運用**: 「!」が出ている間は、小窓の下の取得状態の行で、失敗した DB と種類を確かめる。

## 決定しないこと

- **通知で知らせること**: `docs/overview.md` の「v2」の「将来検討」に置く。署名して配布するようになったときに決める。
- **アイコンの色や形で状態を表すこと**: 件数の文字がメニューバーで邪魔になったときに決める。
