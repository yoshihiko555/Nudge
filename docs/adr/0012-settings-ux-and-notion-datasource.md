# ADR-0012: 設定の汎用化と Notion Data Source 対応

## 決定
- Notion API バージョンは既定で `2025-09-03` を利用し、設定 UI からは非表示にする
- プロパティ取得は Data Source エンドポイントを優先し、旧バージョンの場合は Database エンドポイントにフォールバックする
- 設定 UI で Database ID から Data Source / タイトル / プロパティ一覧を自動取得し、候補を提示する
- 初回セットアップ判定は「トークン + タスク/習慣のいずれか 1 件設定」で OK とする
- トレイメニューは設定された DB 名で動的生成する
- 習慣の曜日チェック列は習慣設定のみで扱い、タスク設定からは除外する

## 理由
- 個人依存の設定項目を減らし、初回セットアップの負担を下げたい
- Notion の `2025-09-03` で Data Source モデルに移行したため対応が必要
- 既存ユーザーの設定互換は維持したい

## 代替案
- Notion API バージョンを手入力のまま維持する
- プロパティ名は手入力のみとする
- トレイメニューを固定（タスク/習慣）にする

## 影響
- 設定 UI / Notion クライアント / トレイメニューの挙動が変わる
- Data Source が複数ある Database は引き続き非対応
- 旧設定の `notion_version` が残っていても既定バージョンに引き上げて動作する
